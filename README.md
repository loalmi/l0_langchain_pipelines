# NLP Lab 1 — Пайплайны обработки данных на основе LangChain и LLM

Лабораторная работа № 1. Прототип интеллектуального интерфейса к каталогу товаров: LLM интерпретирует запрос на естественном языке, программа валидирует параметры и выполняет поиск по SQLite.

## Состав репозитория

| Файл | Назначение |
|---|---|
| `NLP_Lab1.ipynb` | Основной ноутбук со всеми частями работы (1–5) |
| `db_setup.py` | Скрипт инициализации SQLite-базы `products.db` (17 товаров) |
| `search.py` | Схема `ProductQuery` и функция поиска `search_products` |
| `requirements.txt` | Зависимости |
| `results/*.json` | Артефакты выполнения (сохранённые результаты тестов) |
| `REPORT.md` | Отчёт по работе |

## Требования

- Python 3.10+
- Токен OpenRouter (модель `qwen3.8-27b`)

## Установка

1. Создать и активировать виртуальное окружение:

   `python -m venv venv`

   Windows: `venv\Scripts\activate`
   Mac/Linux: `source venv/bin/activate`

2. Установить зависимости:

   `pip install -r requirements.txt`

3. Создать файл `.env` в корне проекта (он в `.gitignore`, в репозиторий не попадает):

   `OPENROUTER_API_KEY=sk-or-ваш_токен`

## Запуск

1. Инициализировать базу данных:

   `python db_setup.py`

   Должно вывести: `База products.db создана, добавлено 17 товаров.`

2. Открыть `NLP_Lab1.ipynb` в VS Code или Jupyter.

3. Выбрать kernel — созданный `venv` (Python 3.x).

4. Выполнить ячейки по порядку сверху вниз. Ноутбук состоит из частей 1–5, каждая часть подписана markdown-заголовком.

## Примечания

- Токен читается из переменной окружения `OPENROUTER_API_KEY`; в коде, отчёте и репозитории его нет.
- Модель вызывается через OpenRouter (`https://openrouter.ai/api/v1`), а не через университетский сервер, поэтому VPN не требуется.
- Результаты выполнения сохраняются в `results/*.json` при запуске соответствующих ячеек.
